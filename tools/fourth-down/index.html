About this version

The recommendation engine uses the denser cfb4th-aligned surface when available, with a local approximation fallback. The goal here is simple: make the model easy to pressure-test.

Yard line uses a 1–99 scale from your own goal line: 1 = own 1, 50 = midfield, 58 = opponent 42, 99 = opponent 1.
